# Contributing to Bespoke Stay Studio

Thank you for your interest in improving this hospitality website methodology.

## What Belongs Here

This repository contains **reusable, generic methodology** — creative workflows, quality standards, templates and automation that apply across different hospitality projects.

### Do Contribute

- Improvements to creative direction methodology.
- Better templates for research, brand analysis or delivery.
- New reference guidance for underserved property types.
- Script improvements for project initialization or validation.
- Accessibility, performance or SEO best practices.
- Corrections to documentation.

### Do Not Contribute

- Client-specific assets, research or business information.
- Private photographs, logos or brand materials.
- Credentials, API keys or machine-specific configuration.
- Personal Obsidian vault notes or memory entries.
- Technology stack mandates that restrict creative freedom.

## How to Contribute

1. Fork the repository.
2. Create a feature branch: `git checkout -b improve-creative-direction`.
3. Make your changes.
4. Run validation: `python3 scripts/validate-skill.py`.
5. Commit with a meaningful message: `git commit -m "feat: add guidance for heritage hotel typography"`.
6. Push and open a Pull Request.

## Commit Messages

Follow [Conventional Commits](https://www.conventionalcommits.org/):

- `feat:` New capability or reference document.
- `fix:` Correction to existing guidance.
- `docs:` Documentation improvements.
- `chore:` Maintenance, formatting, tooling.

## Philosophy

Improvements should make the methodology more effective without making it more restrictive. The goal is better creative judgment, not more design rules.

Every property deserves something original. Contributions should protect that principle.
